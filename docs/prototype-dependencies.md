# Prototype dependencies and validation boundary

Milestone 3 uses the independent `prototypes/aether-poc/Cargo.toml` and its own `Cargo.lock`. Package `aether-poc` is version 0.1.0, edition 2024, rust-version 1.99, publish false. The tested local compiler is rustc 1.99.0 (b940084d7eb6a299eb4bfeb8e34901bc051e7ac4), Cargo 1.99.0 (5f94df4789f005f9a352888e8355ffc645b7ed0e), x86_64-unknown-linux-gnu. This is one synthetic reference environment, not a supported operating-system range.

Direct dependencies are local `aether-validation` 0.1.0 at `../../tools/aether-validation`, serde exactly 1.0.228 with derive for structured records, and serde_json exactly 1.0.149 for fixture/report interchange. Test-only tempfile exactly 3.27.0 owns disposable fixture copies. Rust standard-library filesystem, TCP, threads and time implement the bounded local demonstration without a networking framework or asynchronous runtime.

The lock contains 34 package entries including both local packages and all transitive/test/platform packages. The validation library brings sha2 0.10.9 for SHA-256 content identities and sha1 0.10.6 solely for pinned upstream Git blob identity, plus serde/serde_json and their dependencies. Exact remaining versions/checksums are in Cargo.lock. The existing validation-tool source/lockfile remains unchanged. No dependencies were downloaded for M3; lock generation and checks use the existing offline cache. A package lock is not a portable host image or production dependency approval.

Arrow, Parquet and DataFusion version selection and their combined compatibility experiment are deferred to Milestone 6, where actual in-memory batches, persisted files and SQL queries can be tested together. Their absence from this harness does not change the Rust/open-storage/query requirement. Metric-parser dependencies may be considered in M4 if required. No GPU/NIC/runtime SDK, eBPF loader, CUDA/NCCL binding, cloud client, central database or Python runtime is included.

Milestone 4 adds runtime parsing, calculation, scenario/comparison and typed-record modules with no new dependencies or Cargo.lock changes. The finite parser is independent of the validation tool's private checker. All accepted M3 source/docs/lock bytes are archived under the M4 predecessor root before live edits; M4 evidence records current source hashes separately. Arrow/Parquet/DataFusion selection remains M6 work.
